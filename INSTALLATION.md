# Installation and Usage
Clone the repository and install the required packages:
```bash
pip install -r requirements.txt
```
After this, you can add your own code/configuration or modify existing files as
needed (see the documentation). After you are done, you can run the training
script:
```bash
python train.py --config config.yaml
```
Substitute `config.yaml` with your actual configuration file. A simple
configuration for the Faustmann model is found in
`config/default_faustmann.yaml`.
