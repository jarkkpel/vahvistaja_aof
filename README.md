# Vahvistaja
Vahvistaja is a tool for solving forest rotation problems using reinforcement
learning. It provides a unified framework for defining a rotation problem, a
reinforcement learning agent, and the agent's training procedure. The current
implementation is aimed to support policy gradient methods.

# Supported Algorithms
The current version implements the Proximal Policy Optimization Algorithm [1]
for both discrete and continuous state and action spaces.

[1] OpenAI. Proximal Policy Optimization. <https://spinningup.openai.com/en/latest/algorithms/ppo.html> Retrieved 5.11.2025.
